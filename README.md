# APEX Fitness - Landing Page Premium

Landing page completa para gimnasio premium con diseño moderno y alto enfoque en conversión.

## 🚀 Inicio Rápido

```bash
# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Build para producción
npm run build

# Iniciar servidor de producción
npm start
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## 🎯 Características

- ✅ Diseño moderno tipo Nike/Gymshark/Apple Fitness
- ✅ Animaciones suaves con Framer Motion
- ✅ 100% Responsive (Mobile-first)
- ✅ Optimizado para conversión
- ✅ Componentes modulares y reutilizables
- ✅ TypeScript para mayor confiabilidad
- ✅ Tailwind CSS para estilos

## 📦 Secciones Incluidas

1. **Hero** - Propuesta de valor impactante
2. **Benefits** - 6 beneficios clave del gimnasio
3. **Pricing** - 3 planes (Básico, Pro, Premium)
4. **Trainers** - 4 perfiles de entrenadores
5. **Facilities** - Instalaciones y equipamiento
6. **Schedule** - Horario semanal completo
7. **Testimonials** - 6 testimonios con resultados
8. **FAQ** - 8 preguntas frecuentes
9. **CTA** - Llamado a la acción final + footer

## 🛠️ Stack Tecnológico

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## 🎨 Personalización

Modifica los colores principales en `tailwind.config.js`:

```js
colors: {
  primary: '#ff3366',    // Color principal
  secondary: '#1a1a1a',  // Color secundario
  accent: '#00ff88',     // Color de acento
}
```
